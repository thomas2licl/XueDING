# LocalLife — UI 视觉与交互动画设计规范

**设计版本：** V1.4（V1.4：沙漏 4.9 章实装定稿——翻转启动+沙量 60% 规则+滚轮微调暂缓；V1.3：页点指示器自动隐藏定稿；V1.2：闹钟重复档位定稿 4 档；V1.1：取消功能导航页，改为一级页面横滑直接切换；V1.0：初版）  
**产品名称：** LocalLife  
**设计对象：** ESP32-S3-Touch-LCD-3.49  
**屏幕分辨率：** 640 × 172 px  
**显示方向：** 横屏（支持左右横向自动旋转）  
**产品形态：** 方形蓝色外壳 + 黑色正面显示面板

---

# 一、产品整体设计定位

## 1.1 设计理念

LocalLife 是一款面向日常生活的智能桌面终端。

它不仅是一台时钟，也是一款能够提供天气、提醒、声音、倒计时和氛围照明的桌面生活助手。

整体 UI 设计应体现以下特点：

- **简约：** 去除不必要的装饰，避免复杂卡片和多余信息。
- **精致：** 通过字体、间距、图标和细节动画体现产品质感。
- **直观：** 用户不需要学习复杂操作，就能理解界面和功能。
- **安静：** 不主动制造视觉干扰，平时保持安静的桌面陪伴属性。
- **统一：** 所有功能页面遵循相同的视觉规范和交互逻辑。

核心设计原则：

> 界面应该服务于信息，而不是让信息服务于界面。

## 1.2 硬件外观与视觉风格

设备采用方形蓝色外壳，正面为黑色显示面板。

UI 应当与硬件外观形成统一的视觉语言：

- 默认背景采用接近纯黑的深色。
- 主要文字采用柔和白色。
- 品牌强调色采用蓝色，与外壳颜色呼应。
- 辅助信息使用不同明度的灰色。
- 天气警告和重要提醒使用橙色或红色。
- 避免大面积渐变、玻璃拟态、复杂阴影和高饱和度装饰。

整体风格参考高端电子产品的极简仪表盘，而不是传统智能家居控制面板。

# 二、屏幕尺寸与布局规范

## 2.1 画布要求

所有页面必须严格按照以下尺寸设计：

- 画布宽度：640 px
- 画布高度：172 px
- 默认方向：横屏
- 禁止竖屏 UI 布局。
- 所有页面必须考虑屏幕实际显示区域，不允许出现内容裁切。

建议使用 8 px 基础间距体系。

主要布局区域：

- 左右安全边距：12 px。
- 上下安全边距：8 px。
- 页面内容高度：约 156 px。
- 页面内容宽度：约 616 px。

## 2.2 布局设计原则

由于屏幕高度只有 172 px，必须充分利用横向空间。

推荐：

1. 左右分栏布局。
2. 横向排列的信息模块。
3. 少量、紧凑的信息组合。
4. 重要信息优先显示。
5. 尽量避免上下滚动。
6. 避免手机端常见的大尺寸卡片和大面积留白。

每个页面应当有一个明确的视觉中心。

## 2.3 字体规范

建议采用现代无衬线字体。

| 内容 | 建议字号 |
|---|---:|
| 主页面时间 | 48～64 px |
| 页面主标题 | 18～22 px |
| 核心数值 | 24～32 px |
| 普通正文 | 13～16 px |
| 辅助文字 | 10～12 px |

具体字号需要根据实际字体、字重和屏幕可读性进行调整。

时间数字建议采用具有良好数字辨识度的字体，数字宽度尽量保持一致，避免时间变化时产生明显的横向跳动。

## 3.1 基础色彩

| 名称 | 色值 | 用途 |
|---|---|---|
| 主背景 | #080A0E | 所有页面默认背景 |
| 次级背景 | #111722 | 选中区域、局部底色 |
| 主文字 | #F3F5F7 | 时间、标题、核心信息 |
| 次级文字 | #A0A9B6 | 普通说明 |
| 弱化文字 | #626D7B | 辅助信息 |
| 品牌蓝 | #3988E8 | 选中状态、重点交互 |
| 浅蓝 | #65A8FF | 天气图标、动态效果 |
| 正常绿 | #42C98A | 成功、正常状态 |

- 黑色是整个 UI 的基础。
- 蓝色是主要交互强调色。
- 白色用于最重要的信息。
- 灰色用于次要信息。
- 橙色和红色只在需要提醒时出现。

不要让每个功能页面都充满彩色图标。

# 四、页面设计

## 4.1 开机欢迎页面

**设计目标：** 简洁、快速、有品牌辨识度。

开机过程：

1. 初始化显示区域时保持纯黑。
2. 清屏完成后再开启背光。
3. 显示 LocalLife 品牌欢迎画面。
4. 欢迎画面持续 3 秒。
5. 自动进入时钟主页面。

欢迎页面设计：

- 纯黑背景。
- 中间显示 LocalLife 品牌名称或 Logo。
- Logo 使用白色，局部使用蓝色。
- 不显示多余的版本信息、加载进度条或装饰动画。

动画：

- Logo 淡入：300 ms。
- 保持显示。
- 页面切换：200 ms 淡出。

如果禁用了开机图，直接从黑屏进入主界面。

## 4.2 时钟主页

**设计目标：** 让时间成为第一视觉中心，同时自然展示天气和设备状态。

推荐采用三栏横向布局：

- 左侧：日期和星期。
- 中间：当前时间。
- 右侧：天气和温度。
- 电池信息放在页面右上角或天气区域上方。

信息优先级：

1. 当前时间。
2. 当前天气和温度。
3. 日期和星期。
4. 电池电量及充电状态。

主页内容：

- 当前时间，精确到分钟或秒。
- 年月日、星期。
- 当前地点。
- 当前天气图标。
- 当前温度和体感温度。
- 天气异常提醒。
- 电池百分比及充电状态。

天气异常时显示简短提醒，例如：

「今日降温 6℃，记得添衣。」

动画：

- 时间变化采用轻微淡入或数字平滑更新。
- 分钟变化不进行大幅度翻转动画。
- 天气图标可以使用低频、轻量的动态效果。
- 降温提醒出现时，从天气区域轻微淡入。
- 电量变化只更新电池图标和数字，不进行明显动画。

交互：

- 点击天气区域进入天气详情。
- 点击时间区域进入闹钟页面。
- 左右滑动切换到相邻功能页面（见 4.3）。
- 语音唤醒时显示轻量语音交互状态。

主页必须始终保持简洁，避免把所有功能入口都塞进主页。

## 4.3 页面横滑切换（V1.1 修订：取消功能导航页）

**设计目标：** 以最直接的方式在功能页面间移动，少一级跳转。

一级页面平级排列，**左右滑动直接切换**，页面随滑动方向滑入滑出；不设功能导航页。

页面顺序（线性排列，不循环）：

> 主页 → 天气 → 闹钟 → 提醒 → 声音中心 → 图片相册 → 沙漏 → 小夜灯 → 设置

手势与动画规范：

- 向左滑：进入下一页；向右滑：返回上一页。
- 首页再右滑、末页再左滑无任何动作（不循环，不回弹，保持安静）。
- 切换动画：整页横移（MOVE），180～220 ms，方向与手势一致；非跟手拖动（触发式）。
- 页面隐藏时暂停其刷新与动画（不可见页零开销）。

页点指示器（V1.3 定稿，2026-11-19 用户建议）：

- 位置：底部居中，9 个小圆点，当前页品牌蓝、其余弱灰；置于 top layer，不随切页移动、不挡触摸。
- **自动隐藏**：触摸（按下/抬起）淡入 150 ms；**3 秒无操作自动淡出**；二级页面期间隐藏，返回一级页后点亮 3 秒；程序切页（语音/场景联动）同样点亮 3 秒。
- 平时页面保持干净，符合"安静"设计理念。

手势冲突消解：

| 场景 | 规则 |
|---|---|
| 二级页面（新建/编辑/详情等） | 仅**手势起点在屏幕左边缘约 40px 内**的右滑 = 返回上一级；非边缘右滑不切页 |
| 图片相册页 | 左右滑动留给切换图片；本页切页改用**上下滑**（初定，真机验证） |
| 含滑动控件的页面（音量条、滚轮等） | 控件优先消费滑动，不触发切页 |

二级页面的进入/返回动画沿用各页面定义（新建页从右侧轻微滑入、返回向右滑出）。

## 4.4 天气页面

**设计目标：** 让用户快速了解当前天气和未来天气变化。

页面采用横向分区布局。

左侧区域：

- 当前地点名称。
- 天气图标。
- 当前温度。
- 体感温度。
- 湿度。

中间区域：

- 未来几小时天气趋势。
- 温度变化曲线。
- 降雨概率。
- 降雨时段。

右侧区域：

- 关注地点。
- 目的地温度。
- 两地温差。
- 通勤天气提醒。

温度曲线采用简洁蓝色线条，不使用复杂背景网格。

天气提醒：

- 降温提醒使用橙色。
- 降雨提醒使用蓝色。
- 严重天气提醒使用红色。

动画：

- 温度曲线从左向右绘制。
- 天气图标使用轻量动态效果。
- 切换地点时采用内容淡出、淡入。
- 天气提醒出现时轻微高亮，不使用闪烁警告。

今天与昨天的温度对比：

- 使用简洁的温度变化数字。
- 温差较大时显示橙色提示。
- 无历史快照时不显示对比区域。

## 4.5 闹钟页面

**设计目标：** 快速查看和管理闹钟。

页面分为：

- 闹钟列表。
- 闹钟时间。
- 重复周期。
- 启用状态。
- 新建闹钟入口。

采用横向列表或紧凑排列方式。

新建和编辑页面：

- 时间选择器。
- 重复周期选择。
- 四档：单次、每日、周一到周五、周一到周六（2026-11-19 需求定稿;任意星期组合暂缓）。
- 保存和取消。

动画：

- 新建页面从右侧轻微滑入。
- 返回页面向右滑出。
- 闹钟启用开关采用平滑滑动。
- 保存成功时显示短暂的蓝色确认反馈。

闹钟响起：

- 屏幕显示醒目的当前闹钟时间。
- 显示关闭和贪睡操作。
- 配合语音播报和早晨天气信息。
- 避免使用过于刺眼的闪烁动画。

## 4.6 提醒事项页面

**设计目标：** 让提醒事项容易查看、创建和管理。

页面显示：

- 提醒内容。
- 提醒时间。
- 日期。
- 周期状态。
- 是否启用。

新建提醒页面：

- 输入提醒内容。
- 设置日期。
- 设置时间。
- 设置重复周期。
- 保存提醒。

动画：

- 新提醒创建后淡入列表。
- 删除时轻微淡出。
- 到达提醒时间时，界面显示明显但克制的提醒状态。
- 重要提醒支持语音播报。

## 4.7 声音中心页面

**设计目标：** 让播放操作直观，界面具有放松、舒适的氛围。

页面布局：

- 左侧显示声音类别。
- 中间显示当前声音名称。
- 右侧显示播放控制。
- 下方显示音量和定时关闭。

声音分类：

- 自然声音。
- 白噪音。
- 助眠声音。
- 专注声音。

播放界面：

- 显示当前播放名称。
- 播放、暂停、停止。
- 音量调节。
- 睡眠定时。

动画：

- 播放时显示缓慢变化的波形。
- 暂停时波形逐渐停止。
- 音量变化时显示简洁的音量反馈。
- 切换声音时采用轻微淡入淡出。

波形动画应当缓慢、柔和，不能像音乐播放器一样频繁跳动。

睡眠模式下，页面逐渐降低亮度，播放结束后按照系统策略进入低亮度或息屏状态。

## 4.8 图片相册页面

**设计目标：** 让设备成为一台简洁的桌面电子相框。

默认采用图片全屏展示。

- 图片尽可能铺满屏幕。
- 按比例缩放。
- 不允许强制拉伸。
- 根据图片比例选择合适的裁切或留黑策略。

交互：

- 左右滑动切换图片。
- 点击屏幕显示简短控制信息。
- 支持自动轮播。
- 支持设置轮播间隔。

动画：

- 图片切换采用柔和淡入淡出。
- 自动轮播时不显示复杂过渡效果。
- 图片展示期间尽量不显示多余 UI。

## 4.9 沙漏倒计时页面

**设计目标：** 这是 LocalLife 最具特色的交互页面之一，应当具有一定的观赏性。

页面分为两个状态。

### A. 时间设置状态

- 中间显示沙漏。**沙量规则（2026-11-20 定稿）**：初始=下腔平铺 60%、上腔空；计过后的设置态=下腔 60% 锥形（顶部圆头）。
- 旁边显示当前设置的倒计时时长。
- 支持 1、3、5、10、15、30 分钟快捷档位（U5 已实装）。
- 支持滚轮微调（**暂缓**：U5 一期仅档位胶囊,滚轮待需求确认后补）。
- 提供开始按钮。

### B. 倒计时运行状态

- 中间显示动态沙漏。
- 旁边显示剩余时间。
- 沙量与剩余时间严格对应：上腔 60% 起按剩余比例递减；下腔锥形（圆头）按流逝比例长高，封顶 60%（2026-11-20 定稿）。
- 沙子从上半部分逐渐流向下半部分。
- 暂停时沙子停止流动。
- 恢复后继续流动。

沙漏动画要求：

- 沙子颗粒运动连续、自然。
- 上下沙量与实际剩余时间保持同步。
- 不能出现动画已经结束但倒计时还未结束的情况。
- 动画必须由实际计时数据驱动，而不是单纯播放固定循环。

手势：

- 沙漏页面待机状态下，**横放掉头翻转设备即可开始倒计时**——翻转触发方向自适应转屏的同一事件，物理上等于把沙漏倒置，视觉上"翻过来就开始漏"（2026-11-20 定稿，替代竖放手势）。
- **倒计时结束后再次翻转 = 重来**（同时长重新计时,2026-11-20 增补）。
- 运行过程中翻转仅转屏，不触发其他功能；暂停/取消仅通过按钮。

倒计时结束：

- 沙漏动画完成。
- 显示完成状态。
- 播放滴滴提示音。
- 提供取消和重新开始操作。

倒计时期间禁止息屏。

## 4.10 小夜灯页面

**设计目标：** 页面越简单越好，不增加无意义的装饰。

关闭状态：

- 黑色背景。
- 中间显示一个明显的滑动开关。
- 提示文字：滑动开启夜灯。

开启状态：

- 整个屏幕显示纯白色。
- 背光调整至最高亮度。
- 不显示其他图标和文字。

交互：

- 滑动开关开启夜灯。
- 晃动设备可以触发开灯。
- 晃动只负责开灯，不允许关闭。
- 关闭只能通过手动滑动开关完成。

动画：

- 开灯时屏幕亮度平滑提升。
- 关闭时亮度平滑降低至黑屏。
- 不允许出现闪烁和突然亮度跳变。

夜灯开启期间禁止息屏。

## 4.11 设置页面

**设计目标：** 让设备设置保持清晰、有序。

采用左侧分类导航、右侧具体设置的横向布局。

设置分类：

- 显示设置。
- 亮度设置。
- 时间设置。
- 地点管理。
- 网络设置。
- 语音设置。
- 电源管理。
- 关于设备。

设置页面统一使用：

- 标题。
- 当前设置值。
- 滑动开关。
- 数值调节。
- 简洁的选项列表。

动画：

- 切换设置项时内容淡入淡出。
- 开关采用平滑滑动。
- 亮度变化应当实时反馈。
- 保存成功时给予短暂提示。

# 五、全局交互规范

## 5.1 页面导航

页面层级最多两级：

一级功能页面（横滑平级切换，见 4.3）→ 功能子页面。

所有子页面必须提供：

- 左上角返回按钮。
- 屏幕左边缘向右滑动返回。
- 返回后恢复上一级页面状态。

避免设计多层级菜单。

## 5.2 触摸交互

所有触摸操作需要有明确反馈。

- 点击：轻微颜色变化。
- 选中：蓝色强调。
- 滑动：页面或控件平滑移动。
- 长按：仅在有明确功能时使用。
- 返回：统一使用向右滑动手势。

动画必须避免影响触摸响应。

## 5.3 语音交互

语音唤醒时，在当前页面显示轻量语音状态提示。

建议设计三种状态：

**待机状态**

不显示额外元素，保持当前页面。

**正在聆听**

- 显示蓝色语音波形。
- 显示简短提示：正在聆听。
- 波形随声音输入变化。

**语音处理及反馈**

- 显示简短的处理状态。
- 识别成功后显示简短操作结果。
- 必要时配合中文语音播报。

语音交互不应强制跳转页面，除非用户的操作本身需要打开对应功能。

# 六、动画设计规范

## 6.1 动画时间

| 动画类型 | 建议时间 |
|---|---:|
| 普通点击反馈 | 80～120 ms |
| 开关切换 | 150～200 ms |
| 页面切换 | 180～220 ms |
| 页面淡入淡出 | 150～200 ms |
| 图标选中 | 120～160 ms |
| 亮度渐变 | 200～400 ms |
| 重要提醒 | 200～300 ms |

以上为初始设计参数，后续根据真机显示效果调整。

## 6.2 动画原则

1. 优先使用透明度和位置变化。
2. 避免大面积复杂动画。
3. 不使用没有实际意义的循环动画。
4. 所有动画必须保证信息清晰。
5. 页面切换不能产生明显卡顿。
6. 低功耗状态减少动画和屏幕刷新。
7. 动画不能影响倒计时等实际业务状态。

## 6.3 特殊动画

需要重点设计以下动画：

- 开机 Logo 淡入。
- 主页面时间更新。
- 天气温度曲线。
- 语音交互波形。
- 声音播放波形。
- 沙漏颗粒流动。
- 小夜灯亮度渐变。
- 闹钟触发提醒。
- 低电量提醒。

其中沙漏、小夜灯和主页面是三个重点场景。

# 七、夜间模式与电源状态 UI

## 7.1 USB 供电状态

USB 供电或充电期间：

- 屏幕保持正常运行。
- 不执行自动降亮度策略。
- 夜间只切换到低亮度档位。
- 不自动息屏。

## 7.2 电池供电状态

电池单独供电时：

- 亮屏 20 秒无操作，自动降低亮度。
- 任意触摸或按键操作恢复正常亮度。
- 只有电源键短按可以手动息屏。
- 触摸屏幕不能唤醒息屏设备。

## 7.3 系统事件唤醒

闹钟、提醒和倒计时结束可以主动唤醒屏幕。

事件唤醒后：

- 显示事件内容。
- 进行必要的语音播报。
- 20 秒无用户操作，重新进入低功耗息屏状态。
- 用户主动触摸交互后转为正常亮屏状态。

## 7.4 低电量提醒

| 电量 | UI 表现 |
|---|---|
| ≤20% | 主页显示低电量提醒 |
| ≤10% | 提示并降低亮度 |
| ≤5% | 提示即将关机，执行关机保时策略 |

低电量提醒不应持续闪烁。

# 八、姿态交互设计

设备通过板载 QMI8658 六轴 IMU 检测设备姿态。

必须严格限定手势生效页面。

| 手势 | 生效条件 | 行为 |
|---|---|---|
| 左横 / 右横 | 全局亮屏状态 | 自动旋转 UI |
| 横放掉头翻转 | 沙漏页面待机状态 | 开始倒计时（2026-11-20 定稿,替代竖放） |
| 晃动 | 小夜灯页面前台 | 开启夜灯 |
| 任意手势 | 息屏状态 | 不响应 |

姿态变化不需要额外的视觉装饰动画。

自动旋转时，整个 UI 平滑旋转 180°，并保证旋转后内容完整、方向正确。
