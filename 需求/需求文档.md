# LocalLife — 产品功能需求文档

**版本：** V0.6（V0.5 基础上细化：功耗策略、沙漏倒计时、手势页面限定）  
**项目定位：** 本地优先的智能桌面生活终端  
**硬件平台：** Waveshare ESP32-S3-Touch-LCD-3.49（含 QMI8658 六轴 IMU）

---

## 一、产品定位

LocalLife 是一款面向日常生活的智能桌面设备。

平时作为智能时钟使用，在需要时可以通过语音或触摸屏进行交互，提供天气信息、闹钟提醒、语音播报、白噪音播放、图片展示和夜间照明等功能。

产品强调：

- 本地优先，尽可能减少对云端 AI 服务的依赖。
- 支持离线语音交互和中文语音播报。
- 界面简洁，操作自然。
- 兼顾实用性与桌面陪伴属性。

## 二、产品功能

### 1. 智能时钟

- 显示当前时间、日期和星期。
- 支持闹钟设置。
- 支持单次闹钟、每日闹钟和自定义星期重复。
- 支持贪睡功能。
- 支持触摸屏和语音设置闹钟。
- 支持夜间时钟显示模式。
- **显示方向（V0.2 新增）**：设备为横卧桌面形态，界面默认横屏显示；板载陀螺仪/加速度计（QMI8658）自动检测摆放方位，在左横、右横两个方向间自动旋转界面，保证画面始终正向；不做竖屏显示（竖放姿态保留给倒计时手势，见 §8）。

### 2. 天气助手

提供当前所在地和用户关注地点的天气信息。

**地点管理**

- 支持区县级地点选择。
- 支持设置本地位置。
- 支持设置一个或多个关注地点。
- 地点可以设置名称和用途，例如家庭所在地、工作地点。
- 使用和风天气作为第一版天气数据来源。

**天气查询**

- 当前天气。
- 逐小时天气预报。
- 当日天气变化。
- 降雨概率及降水情况。
- 温度、体感温度、湿度等信息。
- 多地点天气比较。

**通勤天气提醒**

以本地位置和工作地点为例：

- 本地：杭州市西湖区。
- 工作地点：杭州市萧山区。

关注两个区县在不同时间段的天气变化。

重点提醒：
- 出发地和目的地的降雨情况。
- 两地温度及体感温度差异。
- 通勤时间段的天气变化。
- 是否需要携带雨伞或增添衣物。

**天气播报**

- 可以通过语音主动询问天气。
- 可以在闹钟响起时自动播报天气。
- 支持播报本地天气和关注地点天气。
- 天气数据不可用时，提示数据更新时间及缓存状态。

**温度对比与穿衣提醒（V0.4 新增，面向本地地点）**

- 对比**今天与昨天**的温度（最高/最低），基于设备每天自动保存的"当日温度快照"，无需依赖付费的历史天气接口；快照缺失（如首日使用、昨日未通电）时优雅降级不显示对比。
- **突然降温提示**：今日温度较昨日降幅超过阈值（默认 4℃，可设置）时，在主页/天气页给出醒目提醒（如"今日降温 6℃，比昨天明显变冷"）。
- **穿衣建议**：根据今日体感温度（优先）或气温，给出穿衣推荐（如"T恤+薄外套"）；若同时检测到降温，追加提醒加衣（如"比昨天冷 6℃，记得加件毛衣"）。
- 早晨模式播报中联动：闹钟播报天气时自动包含降温提示与穿衣建议，保证出门前获知。
- 降温提醒也适用于关注地点（如工作地点），便于通勤前了解两地情况。

### 3. 语音助手

支持通过语音与设备进行交互。

**离线语音识别**

- 支持唤醒词。
- 支持固定命令词识别。
- 支持查询时间。
- 支持查询天气。
- 支持控制音乐和白噪音。
- 支持设置闹钟和提醒。
- 支持控制屏幕亮度和夜灯。

**离线中文 TTS**

- 将文字转换为中文语音。
- 播报时间、天气和提醒事项。
- 语音反馈设备操作结果。
- 支持调节语速和音量（具体能力后续验证）。

第一阶段以固定命令和离线播报为主，暂不要求实现自由中文对话。

### 4. 提醒事项

- 支持语音创建提醒。
- 支持自定义提醒内容。
- 支持精确到小时和分钟。
- 支持指定日期和时间。
- 支持周期性提醒。
- 支持查看、修改、删除提醒。
- 到达提醒时间后通过屏幕和语音通知。

### 5. 声音中心

提供音乐、自然环境音和白噪音播放功能。

**自然白噪音**

- 雨声、雷雨声。
- 海浪声。
- 溪流声。
- 森林鸟鸣。
- 风声。
- 壁炉燃烧声。

**助眠与放松**

- 白噪音、粉红噪音、棕色噪音。
- 夜间环境音。
- 睡眠定时关闭。
- 音量渐弱和自动停止。

**专注与工作**

- 咖啡馆背景声。
- 图书馆环境声。
- 轻柔氛围音乐。
- 专注模式。

**播放控制**

- 语音控制播放、暂停和停止。
- 音量调节。
- 定时播放和定时停止。
- 支持与睡眠模式、闹钟模式联动。

### 6. 图片相册

- 支持通过蓝牙与手机同步图片。
- 支持图片浏览。
- 支持图片轮播。
- 支持设置轮播间隔。
- 支持作为桌面相框使用。

### 7. 氛围灯与夜间模式

- 支持调节屏幕亮度。
- 支持语音控制屏幕亮度。
- 支持夜间低亮度模式。
- 支持息屏和定时亮屏。
- 支持睡眠模式下渐暗。

**小夜灯（V0.3 细化，当前方案不依赖额外硬件，以屏幕作为光源）**

- 设有小夜灯页面，页面中间有一个滑动开关，滑动该开关即可开灯/关灯。
- **晃动板子可以开灯**（陀螺仪/加速度计检测晃动手势）。
- 开灯表现：**屏幕整屏显示白色，背光调整到最亮**。
- **晃动只开不关**：开灯后无论如何晃动板子都不会关灯。
- **关灯仅有一种方式：手动把滑动开关滑回关闭**。

### 7a. 外观氛围灯（可选，暂缓）

- 支持外观氛围灯控制（如后续增加相应硬件）。

### 8. 倒计时器 / 沙漏（V0.2 新增，V0.6 细化）

利用板载陀螺仪实现的沙漏式倒计时：

- 支持设置倒计时时长，**最长 30 分钟**（快捷档 1/3/5/10/15/30 分钟 + 滚轮微调）。
- 设置后进入**沙漏画面**：满沙静止待机，横屏布局（沙漏居中，旁侧显示剩余时间）。
- **两种启动方式**：手动点击沙漏开始，或**竖放板子开始**（竖放手势仅在沙漏页待机状态时生效）。
- **漏沙动画与剩余时间严格联动**：沙量比例 = 剩余时间比例，暂停则沙停，恢复继续。
- 计时结束：**「滴滴」提示音**（扬声器）+ 屏幕提示；支持取消和重来。
- **倒计时进行中不息屏**（属于观赏/等待场景）。

### 9. 电源与电池（V0.5 新增，V0.6 细化功耗策略）

板载锂电池供电，USB 供电/充电。**功耗总策略由供电状态决定：**

- **电量和充电状态仅在时间主页面显示**（电池图标 + 百分比，充电时显示充电标识）；其他页面不显示，保持小屏简洁。
- 自动识别供电来源（电池 / USB）。

**USB / 充电在线时：全功能运行**
- **不息屏、不执行任何低功耗限制**（夜间仅切换低亮度档位，不灭屏）。

**电池单独供电时：启用低功耗策略**
- **无操作降亮度**：亮屏状态下 **20 秒无操作自动降低屏幕亮度**（降至低亮度档，时间与亮度可设置）；任意触摸/按键操作立即恢复正常亮度。充电（USB）时无此策略。
- **息屏 = 低功耗模式**（两者为同一状态）：
  - 进入：**仅电源键短按手动息屏**（不做无操作超时自动息屏）。
  - 息屏后系统进入低功耗运行：CPU 降频、系统浅睡眠、WiFi 射频休眠。
  - 唤醒：**仅电源键短按唤醒（手机式，触摸屏幕不唤醒）**。
  - **系统事件主动亮屏例外**：闹钟/提醒/倒计时结束会自动亮屏并播报——此时 **20 秒无操作即自动息屏回低功耗**（事件亮屏只为通知，快速回省电）；期间用户一旦触摸交互则转为正常亮屏（适用上面降亮度规则，息屏仍需按键）。
  - 插上充电线立即退出低功耗模式并亮屏（切回 USB 全功能档）。
- **息屏冻结场景**：沙漏计时中、小夜灯开启中——按键也不息屏。
- **联网降频**：天气拉取间隔 2 小时、网络对时间隔 12 小时，WiFi 空闲时休眠射频。
- **无 WiFi 处理**：停止扫描，定时退避探测（约 10 分钟一次）；连续失败进入离线模式，冻结全部网络任务（数据用本地缓存），按键唤醒或插电时再恢复探测。
- **场景化省电**：静止界面场景（沙漏待机/结束、小夜灯等）降低 CPU 运行频率与刷新，交互时立即恢复性能。

**电源键**
- 短按：亮屏 / 息屏切换。
- 长按：关机（现有硬件支持）。

**低电量分级策略**（阈值可设置，默认 20% / 10% / 5%）
- ≤20%：主页横幅提醒 + 语音播报一次。
- ≤10%：自动降低亮度等省电措施。
- ≤5%：语音与屏幕提示后自动**关机保时**（保护 RTC 走时与数据，倒计时内插上充电线可取消）。

**关机后 RTC 走时**能力需真机验证；如不支持断电走时，则文档化降级行为（开机后依赖网络对时）。

## 三、场景联动

不同功能可以组合使用。

### 早晨模式

1. 闹钟响起。
2. 播报当前时间。
3. 查询本地天气和工作地点天气。
4. 分析通勤时间段天气。
5. 播报天气提醒。
6. 显示当天重要天气信息。

### 工作专注模式

1. 播放咖啡馆背景音或自然白噪音。
2. 降低屏幕亮度。
3. 显示时间。
4. 可以结合专注计时功能。

### 睡眠模式

1. 播放助眠白噪音。
2. 屏幕逐渐变暗。
3. 支持设置播放时长。
4. 播放结束后自动停止。
5. 进入低亮度或息屏状态。

## 四、产品交互方式

主要提供四种交互方式：

- **触摸屏：** 页面切换、功能设置、播放控制。统一导航规范：**每个应用页面内的子页面（新建/编辑/详情等）都必须提供返回上一级的操作**——页面左上角统一返回按钮，并支持从屏幕左边缘向右滑动手势返回；页面层级保持简单（主导航页 → 应用子页，最深两级）。
- **语音交互：** 查询信息、创建提醒、控制设备。
- **姿态交互（V0.2 新增，V0.3/V0.6 修订）：** 横放方向自动旋转界面（全局生效）；竖放手势启动倒计时（**仅沙漏页待机时生效**）；晃动板子打开小夜灯（**仅小夜灯页在前台时生效**）——页面限定以避免搬动/拿取板子造成误触发；息屏状态下所有手势不生效。
- **自动运行：** 闹钟触发、天气播报、定时关闭、场景联动。

### 开机体验（V0.7 新增）

开机瞬间不得出现花屏/闪屏：**先清屏为纯黑、再点亮背光**（背光亮起时屏幕必须已是纯黑或有效画面）。开机图：开机后显示品牌/欢迎图 **3 秒**（横屏 640×172、RGB565），随后自动进入主界面；无开机图时由纯黑直接进入主界面。开机图可通过编译开关禁用（调试/产测场景）。

> 遗留（2026-11-13）：app 启动后的防花屏已实现；**bootloader 阶段（约 1s）的花屏受硬件上电默认态所限**（背光 CTRL 上拉+调光脚浮空），app 软件无法触及——解决方案（硬件下拉 / 定制 bootloader）待选，见开发进度文档 §6.5。

## 五、总体设计原则

1. 本地优先：时间、闹钟、提醒和设备控制等核心功能不依赖云端。
2. 离线可用：固定语音命令和中文 TTS 尽可能在设备本地完成。
3. 模块化：各功能独立设计，方便后续扩展。
4. 简洁实用：避免复杂的操作流程和冗余功能。
5. 稳定可靠：网络中断不应影响时钟、闹钟和本地播放等核心功能。
6. 可扩展：为后续手机 App、更多地点和功能联动预留空间。
